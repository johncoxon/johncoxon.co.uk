This is the code for [my academic website](https://www.johncoxon.co.uk), based on an HTML template
called [Dimension](https://html5up.net/dimension) written by [HTML5 UP](https://www.html5up.net)
and released under the [CC BY 3.0 license](http://www.creativecommons.org/licenses/by/3.0/).
Dimension, in turn, uses assets from [Font Awesome](https://www.fontawesome.com) (released under the
[Font Awesome Free license](https://fontawesome.com/license/free)), [jQuery](https://www.jquery.com)
(released under [the MIT license](https://github.com/jquery/jquery?tab=MIT-1-ov-file)), and
[Responsive Tools](https://www.github.com/ajlkn/responsive-tools) (released under
[the MIT license](https://github.com/ajlkn/responsive-tools?tab=License-1-ov-file)).

This version has been modified to use [Jekyll](https://jekyllrb.com), allowing me to serve it from
GitHub.
